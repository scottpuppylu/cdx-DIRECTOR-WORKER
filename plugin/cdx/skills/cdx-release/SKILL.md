# Release after verification

Read the project's release policy and the cdx `docs/07_quality_gates.md` and `tools/CDX-TOOLS.md`. Verify the actual target, candidate ref, complete required test runs, CI for that head, and any unresolved PO acceptance. Use the existing project release path, beginning with its dry run when available. Record the version, commit, verification state, and recovery path. Perform remote publication only within the release authorization already given for the project.
